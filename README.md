# Portfolio 2022

My personal developer portfolio built with React and SCSS, showcasing my projects and skills.

## Built With

- [React](https://reactjs.org/) — UI framework
- [SCSS](https://sass-lang.com/) — styling
- [Create React App](https://github.com/facebook/create-react-app) — project bootstrapping

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
git clone https://github.com/Malcom-Maynard/portfolio-2022.git
cd portfolio-2022
npm install
```

### Running Locally

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### Building for Production

```bash
npm run build
```

Outputs an optimized production build to the `build/` folder.

## Project Structure

```
portfolio-2022/
├── public/        # Static assets
├── src/           # React components and SCSS styles
├── build/         # Production build output
└── package.json   # Dependencies and scripts
```
